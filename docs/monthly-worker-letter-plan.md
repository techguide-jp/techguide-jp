# 作業者向け月次メール

- 配信日は日本時間の毎月1日9時台。登録者一覧に載る全員に、前月の案内、お手紙、アンケートへのリンクを1通にまとめて送る。メール未同期の登録者は既存の配送履歴にスキップとして記録する。
- 前月に精算対象があり、申請・承認の記録がない人には、従来の「3日を目安に申請」の案内と精算リンクを付ける。申請・承認済みと精算対象なしにも、それぞれの状態を記載する。
- 管理モードの「メール通知」から翌月配信分の共通のお手紙を保存する。空欄なら固定文を使う。送信月をキーに保存し、別の管理者が先に更新した内容の上書きを防ぐ。
- 日本時間の月末3日前に翌月配信分のお手紙が空欄なら、管理者へ編集リンク付きのメールを送る。Cronは候補日に起動し、当日かどうかを日本時間で判定する。
- アンケートは Issue #6 で実装したプロフィールの「現在の希望」を使う。稼働時期などの希望、取り組みたい仕事、他社案件への参画希望を本人が随時更新できる。

既存の通知イベントと配送履歴を使い、月初配信は既存の月・作業者単位の通知キーを引き継ぐ。月末の管理者向け通知は送信月単位で記録する。お手紙の保存先と通知種別を追加するマイグレーションを、機能の本番反映前に適用する。

専用テスト環境で、月の長さによる日付の違い、申請状態ごとの文面、既存の通知キーによる重複防止、お手紙の保存と権限、ログイン後のアンケートへの復帰を確認する。

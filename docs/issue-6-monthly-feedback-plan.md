# Issue #6: 月次コメントと現在の希望

## 承認済みの入力内容

| 質問                                                             | 形式                                                 | 閲覧範囲   |
| ---------------------------------------------------------------- | ---------------------------------------------------- | ---------- |
| 運営への感想・要望・質問はありますか？                           | 任意の自由記述                                       | 本人・運営 |
| 対象月の取り組みを振り返って、残しておきたいことはありますか？   | 任意の自由記述                                       | 本人のみ   |
| 今後の稼働量・時期・時間帯の希望を教えてください。               | 任意の自由記述                                       | 本人・運営 |
| 取り組みたい仕事や、仕事の進め方の希望を教えてください。         | 任意の自由記述                                       | 本人・運営 |
| 提携パートナー企業経由の他社業務委託案件への参画を希望しますか？ | 希望する／条件次第で検討したい／現時点では希望しない | 本人・運営 |
| 希望する案件の条件・関心領域を教えてください。                   | 最初の2択の場合のみ、任意の自由記述                  | 本人・運営 |

自由記述は各2,000文字。参画希望に「未回答」の選択肢は設けず、初回の希望保存時に回答する。保存済み回答は引き継ぐ。既存利用者の回答を推測して埋めない。希望の保存を省略した月次申請は可能。

## 保存と更新

- 現在の希望は `worker_profiles` の既存 `availability_note` / `self_assignment_note` を正本としてそのまま使用し、参画希望・条件・希望の版・更新日時を追加する。別の月次希望データは作らない。
- プロフィールと月次詳細へ同じ希望フォームを設置する。保存済みの最新値を初期表示し、精算の有無・承認・支払いに関わらず本人が希望だけ保存できる。希望更新は精算申請・承認・通知に影響しない。
- プロフィールの基本情報保存から希望の書き込みを分離し、古いプロフィール画面から希望が上書きされるのを防ぐ。希望保存は版を比較し、古い画面からの更新を拒否する。
- 「現時点では希望しない」を保存すると案件希望条件を消去する。回答は紹介・参画の確約ではないと説明する。
- 月次コメントは専用の `monthly_feedback` に対象月・本人単位で保存。対象月の保存済み値を初期表示し、初回申請・再申請とコメントは同一transactionで保存する。
- 申請後は承認前までコメントだけの修正が可能。承認と更新の競合はtransaction内で判定し、承認後のコメント変更を拒否する。
- 希望と月次コメントは別の保存ボタンで保存結果を明示する。本人の振り返りは管理者向けレスポンス・メール・通知書・監査本文へ含めない。コメントは精算スナップショットと金額比較へ含めない。
- 失敗時は入力を保持し、成功・失敗・処理中を操作の近くに表示する。管理者は月次詳細で運営コメントと現在の希望を確認できる。

## 実装と検証

新規: 希望・月次コメントの入力型、サービス、repository、共通フォーム、migration、単体・DB・E2Eテスト。
更新: schema、プロフィールと月次詳細のroute、申請保存transaction、テストreset、説明文。

既存値の引継ぎ、精算なしの希望保存、画面間の最新値一致、直接POSTの本人制限、管理者レスポンスからの本人用本文の除外、承認後の変更拒否、入力保持、同時更新、申請との原子的保存、通知への非掲載を検証する。既存の精算ルールV1/V2を維持する。

追加のみのmigrationを生成・適用し、再生成で差分がないことを確認する。本番反映時は既存コードと互換のある追加migrationを先に適用し、新コードから未作成の列・表を参照する時間を作らない。mainへの反映後はCI migrationと本番デプロイを確認する。
